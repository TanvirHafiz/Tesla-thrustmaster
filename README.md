# Tesla Thrustmaster

A Flappy Bird style browser game. Drive the road, hop and fly over traffic with cold gas thrusters, duck under overhead hazards, and finish with a 180 degree roundabout and a flip landing. Choose the Roadster or a battery rickshaw.

Play: tap, click or press Space. Hold to fly, double tap for a midair flip.

Single file, no build step. Open `index.html` in a browser, or serve it with GitHub Pages.
